# Telegram-бот для приёма заказов

Сайт отправляет заказы продавцу через Telegram-бота. Нужны два значения:

- `TELEGRAM_BOT_TOKEN`: токен бота, по нему сайт отправляет сообщения от имени бота;
- `TELEGRAM_CHAT_ID`: ID чата, куда бот присылает заказы.

Всё делается с телефона или компьютера в обычном Telegram, бесплатно.

## Шаг 1. Создать бота

1. Найдите в Telegram официального бота **@BotFather** (с синей галочкой).
2. Отправьте ему команду `/newbot`.
3. Введите **имя** бота: его видят в чате, например `Заказы Зелёная грядка`.
4. Введите **username** бота: латиница, должен заканчиваться на `bot`, например `zelenaya_gryadka_orders_bot`.
5. BotFather пришлёт сообщение с токеном вида:

   ```
   1234567890:AAH...длинная-строка...xyz
   ```

   Это и есть `TELEGRAM_BOT_TOKEN`.

> **Токен — это пароль от бота.** Не публикуйте его, не отправляйте в чаты и не добавляйте в код или git. Если токен утёк, отправьте @BotFather команду `/revoke`, выберите бота и получите новый токен.

## Шаг 2. Выбрать, куда приходят заказы

**Вариант А: личный чат продавца.** Подходит, если заказы принимает один человек.

1. Продавец находит своего бота по username и нажимает **Start** (или отправляет `/start`).
   Без этого бот не сможет ему писать: Telegram запрещает ботам начинать диалог первыми.

**Вариант Б: группа.** Подходит, если заказы видят несколько человек (например, продавец и курьер).

1. Создайте группу в Telegram, например «Заказы с сайта».
2. Добавьте в неё бота как участника.
3. Отправьте в группу сообщение `/start@username_вашего_бота`.
   По умолчанию бот в группе видит только команды, адресованные ему, поэтому нужна именно такая форма.

## Шаг 3. Узнать ID чата

1. Откройте в браузере адрес, подставив свой токен вместо `<ТОКЕН>`:

   ```
   https://api.telegram.org/bot<ТОКЕН>/getUpdates
   ```

2. Найдите в ответе блок `"chat"` и значение `"id"`:
   - личный чат: положительное число, например `"id": 123456789`;
   - группа: отрицательное число, часто начинается с `-100`, например `"id": -1001234567890`.

   Это и есть `TELEGRAM_CHAT_ID`. Минус для группы — часть ID, его нужно сохранить.

3. Если ответ пустой (`"result": []`), снова отправьте боту `/start` (или в группу `/start@username_бота`) и обновите страницу.
   Telegram хранит эти сообщения около суток.

Для этого шага не используйте сторонних ботов вроде «узнай свой ID»: адрес `api.telegram.org` официальный, и токен никуда больше не уходит.

## Шаг 4. Проверить отправку

Откройте в браузере адрес, подставив токен и ID:

```
https://api.telegram.org/bot<ТОКЕН>/sendMessage?chat_id=<ID_ЧАТА>&text=Проверка
```

В чате продавца (или в группе) должно появиться сообщение «Проверка» от бота.

## Шаг 5. Передать значения сайту

**Локально**, для `npm run dev`: создайте в корне проекта файл `.env` по образцу `.env.example`:

```
TELEGRAM_BOT_TOKEN=1234567890:AAH...xyz
TELEGRAM_CHAT_ID=123456789
```

Файл `.env` уже в `.gitignore`, в git он не попадёт.

**На Netlify:** добавьте те же две переменные в настройках проекта, см. [netlify.md](netlify.md), шаг 4.

## Рекомендация: отдельный бот для тестов

Чтобы тестовые заказы не приходили продавцу, создайте второго бота (или вторую группу) для разработки. Его значения пишите в локальный `.env`, а значения «боевого» бота — только в Netlify.
